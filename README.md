# Ayush Negi — Personal Portfolio

Elegant, no-photo developer portfolio built with Next.js 14, React and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production

```bash
npm run build
npm start
```

## Deploy

The project can be deployed directly to Vercel after pushing it to GitHub.
